번역 패치 제작 및 게시 안내

게임에 포함된 텍스트를 번역하고 Steam 창작마당에 게시하는 방법입니다. 번역 편집은 웹 브라우저에서 진행하지만, Steam 게시는 별도의 Windows 업로더가 필요합니다.

번역 웹앱 실행

Steam 공식 번역 패치 제작·설치 가이드 (영어)

이용 시작: 2026년 10월 27일 17:00(KST) 정식 출시부터. 데모는 번역 패치를 지원하지 않으며 Steam Next Fest 종료 후 제공을 종료할 예정입니다.

준비물

Steam에 설치된 ANTI-ANTI, 최신 웹 브라우저. Excel은 선택 사항입니다. 사용자 글꼴을 쓴다면 재배포가 허용된 TTF/OTF/TTC 파일 및 라이선스 문서가 필요합니다.

카탈로그는 사이트에서 제공하지 않습니다. 게임 설치 폴더에서 가져와야 합니다. 설치본에 카탈로그가 없는 경우 해당 빌드에 포함되었는지 확인해야 합니다.

1. 게임의 번역 카탈로그 불러오기

  1. Steam 라이브러리에서 ANTI-ANTI를 우클릭합니다.
  2. 관리 → 로컬 파일 찾아보기로 설치 폴더를 엽니다.
  3. Anti Anti_Data/StreamingAssets/Translation/translation_catalog.json을 찾습니다. *_Data 폴더 이름은 실행 파일명에 따라 달라질 수 있습니다.
  4. 웹앱의 번역 카탈로그 (.json)에서 파일을 선택합니다.

이 JSON에는 번역할 문장과 한국어 원문·공식 영어·일본어 참고 문구가 담겨 있습니다. XLSX를 먼저 불러올 수는 없습니다. 카탈로그를 불러온 후에만 기존 XLSX를 가져올 수 있습니다.

2. 번역 작업: 웹에서 직접 입력하거나 XLSX 사용

두 가지 작업 방법 중 하나를 선택합니다. 별도의 로컬 번역 앱은 필요하지 않습니다.

A. 웹에서 편집

언어 코드(예: es), 언어 표시명(예: Español), 번역팩 ID, 제작자, 버전을 입력합니다. 번역할 항목을 선택하고 내 번역에 작성합니다. 검색·분류·번역 상태 필터를 사용할 수 있습니다. 중간 결과를 보관할 때는 작업 양식 저장 → 작업 양식 다운로드를 이용하세요.

B. Excel에서 편집

작업 양식 저장을 누른 다음 화면에 나타나는 작업 양식 다운로드 링크로 XLSX를 저장합니다. Excel 등에서 각 번역 시트의 Translation 열을 편집합니다. Korean·English·Japanese와 Ref_ 참고 시트, 주소와 해시 열은 고치지 않습니다. 기존 영어·일본어 번역을 새롭게 작성하려면 언어 코드를 en 또는 ja로 설정하고 Translation 열에 수정 번역을 적습니다. 공식 참고 열은 그대로 둡니다. 웹앱에서 JSON 카탈로그를 다시 불러온 뒤 기존 작업용 XLSX 불러오기로 이어서 작업합니다.

상단의 한국어/English 선택은 웹사이트 설명 언어만 변경합니다. 제작할 번역팩의 대상 언어는 작업 화면의 ‘언어 코드’ 필드에서 별도로 설정합니다.

3. 필수 표식과 글꼴

⟦T1⟧ 등의 필수 표식은 번역문에 유지해야 하며 삭제·중복할 수 없습니다. 민감 표현 가리기 대상 행은 번역문에서 가릴 표현도 지정합니다. 미번역이거나 원문이 바뀐 행은 공식 번역으로 대체됩니다.

글꼴은 선택 사항입니다. 돋움(대사·UI), 바탕(나레이션), 효과음에 각각 지정할 수 있으며, 파일을 넣었다면 재배포 라이선스 문서도 제출해야 합니다. 글꼴을 지정하지 않으면 게임 기본 글꼴을 사용합니다.

4. 검증 및 게시용 ZIP 다운로드

  1. 번역 검사를 실행하여 오류를 수정합니다.
  2. 게시용 팩 만들기를 눌러 파일을 생성합니다.
  3. 화면에 나타나는 게시용 팩 다운로드 링크에서 antianti-publishing-pack.zip을 저장합니다.

5. Steam 창작마당 게시 (별도 프로그램 필요)

  1. Windows 게시 도구 ZIP 다운로드
  2. 압축을 전부 해제한 다음 TranslationPatchTool.Publisher.exe를 실행합니다.
  3. 게임을 소유한 Steam 계정으로 로그인합니다.
  4. 동일한 카탈로그와 웹앱에서 생성한 게시용 ZIP을 선택해 게시를 진행합니다.

Translation Patch Creation and Publishing Guide

Translate game text and create a pack for Steam Workshop. Editing runs in your web browser. Publishing to Steam Workshop requires a separate Windows uploader.

Open translation editor

Official Steam translation patch guide (English)

Available from: October 27, 2026, 5:00 PM KST with the full release. The demo does not support translation patches and will be withdrawn after Steam Next Fest.

What you need

ANTI-ANTI installed through Steam and a current web browser. Excel is optional. Custom fonts require a redistributable TTF/OTF/TTC file and its license documentation.

The catalog is not downloaded from this website. Obtain it from your installed game. If it is missing, confirm whether your installed build includes a translation catalog.

1. Load the game's translation catalog

  1. Right-click ANTI-ANTI in your Steam Library.
  2. Choose Manage → Browse local files.
  3. Find Anti Anti_Data/StreamingAssets/Translation/translation_catalog.json. The *_Data folder name may vary with the game executable.
  4. Select this JSON in the web editor's Translation catalog (.json) field.

This file contains translatable entries, Korean source text, and official English and Japanese references. The catalog must be loaded before importing a previously saved XLSX.

2. Translate in the browser or with XLSX

Choose either workflow. You do not need a separate desktop translation application.

A. Edit directly in your browser

Enter a locale code (such as es), a display name (such as Español), pack ID, author, and version. Select an entry and type into Your translation. You can search and filter by category or translation status. To keep a backup, use Save workbook → Download workbook.

B. Edit with Excel

Click Save workbook, then the Download workbook link that appears. Edit the Translation column on the translation sheets in Excel or another XLSX editor. Do not change the Korean, English, Japanese, or Ref_ reference sheets, addresses, or hash columns. You can create alternative English or Japanese translations: set the language code to en or ja and enter your revised text in Translation, leaving the official reference columns unchanged. Back in the web app, load the JSON catalog first and then select Continue a workbook (.xlsx).

The 한국어/English dropdown changes only the website's display language. Set the language your patch translates into separately, using the editor's locale code field.

3. Required markers and fonts

Keep required markers such as ⟦T1⟧ in the translation exactly once; do not remove or duplicate them. For sensitive-content entries, specify the phrases to hide in the translated text. Missing or outdated translations fall back to official game text.

Fonts are optional. You can choose fonts for dialogue/UI, narration, and sound effects separately. If you supply a font file, include its redistribution license document. Unspecified roles use the game's default fonts.

4. Validate and download the publishing ZIP

  1. Click Check translation and resolve any errors.
  2. Click Build publishing pack.
  3. Use the Download publishing pack link to save antianti-publishing-pack.zip.

5. Publish to Steam Workshop (separate program required)

  1. Download the Windows uploader ZIP.
  2. Extract the entire ZIP and run TranslationPatchTool.Publisher.exe.
  3. Sign into a Steam account that owns the game.
  4. Select the same game catalog and the publishing ZIP created in your browser, then submit to Steam Workshop.

How players apply a pack

Subscribe to the translation pack through Steam Workshop. After the download is complete, start the game, select the pack in the language menu, and restart the game. This is the intended behavior; full release-build application remains unverified.
