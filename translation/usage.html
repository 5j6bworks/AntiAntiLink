ANTI-ANTI 번역 패치 제작 및 게시 안내

게임의 대사와 UI 텍스트를 번역하고 Steam 창작마당에 게시하는 방법입니다. 번역 편집은 웹 브라우저에서 진행하며, 창작마당 게시에는 별도 Windows 프로그램이 필요합니다.

번역 웹앱 실행

준비물

Steam에 설치된 ANTI-ANTI, 최신 웹 브라우저. Excel은 선택 사항입니다. 사용자 글꼴을 쓴다면 재배포가 허용된 TTF/OTF/TTC 및 라이선스 문서가 필요합니다.

카탈로그는 이 사이트에서 제공하지 않습니다. 설치된 게임에서 직접 선택해야 합니다.

1. 카탈로그 찾기

  1. Steam 라이브러리에서 ANTI-ANTI를 우클릭합니다.
  2. 관리 → 로컬 파일 찾아보기를 선택해 게임 설치 폴더를 엽니다.
  3. Anti Anti_Data/StreamingAssets/Translation/translation_catalog.json 파일을 찾습니다. 실행 파일명에 따라 *_Data 폴더명이 달라질 수 있습니다.
  4. 번역 웹앱의 게임 번역 카탈로그 (.json) 선택란에서 이 파일을 엽니다.

카탈로그에는 번역 대상 ID, 한국어 원문, 공식 영어·일본어 참고 텍스트가 포함됩니다. 파일이 없다면 현재 설치된 게임 빌드에 카탈로그가 포함되어 있는지 확인해야 합니다.

2. 번역 작성: 웹 편집 또는 Excel

두 방법 중 하나를 선택할 수 있습니다. Excel이나 별도 번역 프로그램을 반드시 설치할 필요는 없습니다.

웹에서 직접 번역

언어 코드(예: es), 게임에 표시할 언어 이름(예: Español), 번역팩 ID, 제작자, 버전을 입력합니다. 항목을 검색하거나 분류·번역 상태로 필터링하고 내 번역에 번역문을 작성합니다. 작업 내용을 보관하려면 작업용 XLSX 생성 → 작업 양식 다운로드를 이용하세요.

Excel에서 번역

작업용 XLSX 생성을 누르고 화면에 나타나는 작업 양식 다운로드 링크를 눌러 파일을 저장합니다. Excel에서 각 번역 시트의 Translation 열에 번역을 입력합니다. Korean, English, Japanese 및 Ref_ 시트는 참고용이며 주소·해시·원문을 변경하지 마세요. 웹앱에 돌아와 카탈로그를 먼저 불러온 뒤 기존 작업용 XLSX 불러오기로 이어서 작업합니다.

3. 번역 규칙 및 글꼴 설정

⟦T1⟧ 등 필수 표식은 번역에서 누락하거나 중복시키면 안 됩니다. 원문과 위치가 달라도 되지만 개수는 유지해야 합니다. 게임 명령을 임의로 입력하면 검증이 거부될 수 있습니다. 민감 표현 가리기 대상 행은 번역문에서 가릴 표현도 지정하세요. 미번역 또는 원문이 변경된 행은 공식 번역으로 대체될 수 있습니다.

글꼴은 선택 사항입니다. 돋움(대사·UI), 바탕(나레이션), 효과음 역할별로 설정할 수 있습니다. 글꼴 파일을 지정했다면 재배포 라이선스 문서도 필요합니다. 지정하지 않은 역할은 게임 기본 글꼴을 사용합니다.

4. 검사 및 게시용 ZIP 생성

  1. 번역 검사를 실행하고 오류를 해결합니다.
  2. 게시용 팩 만들기를 실행합니다.
  3. 화면의 게시용 팩 다운로드 링크를 눌러 antianti-publishing-pack.zip을 저장합니다.

5. Steam 창작마당 게시

  1. Windows 게시 도구 ZIP 다운로드
  2. ZIP 전체를 압축 해제합니다. TranslationPatchTool.Publisher.exe를 실행합니다.
  3. 게임을 소유한 Steam 계정으로 로그인합니다.
  4. 번역 작업에 사용한 카탈로그와 생성한 게시용 ZIP을 선택해 창작마당 게시를 진행합니다.

ANTI-ANTI Steam 창작마당

Steam 서버 게시 → 다른 계정 구독 → 배포판 게임 적용의 전체 흐름은 아직 최종 검증되지 않았습니다. 게시 도구의 작동을 보장하는 안내가 아닙니다.

파일 종류 및 배포 제한

게임 원문과 작업용 XLSX를 외부에 배포하지 마세요. 번역 패치 배포는 Steam 창작마당으로 제한됩니다.

플레이어 적용

Steam 창작마당에서 번역팩을 구독하고 다운로드 완료 후 게임을 실행합니다. 게임의 언어 목록에서 해당 번역팩을 선택하고 게임을 다시 시작하면 적용되는 구조입니다. 실제 배포판의 전체 적용 검증은 남아 있습니다.

English: Quick instructions

  1. Install ANTI-ANTI on Steam. Open Manage → Browse local files.
  2. Select *_Data/StreamingAssets/Translation/translation_catalog.json in the browser editor.
  3. Translate directly in the browser or export a working XLSX, edit only the Translation column, and re-import it after loading the catalog.
  4. Keep required tokens, and optionally choose fonts and include their redistribution license.
  5. Validate, build, and download the publishing ZIP.
  6. Download and extract the separate Windows uploader, run TranslationPatchTool.Publisher.exe, sign into Steam, and submit the catalog and publishing ZIP.

Never distribute the catalog or working XLSX. Publish packs only through Steam Workshop. Full Workshop and release-game end-to-end operation is not yet verified.
